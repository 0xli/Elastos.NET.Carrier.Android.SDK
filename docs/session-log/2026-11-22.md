# 2026-11-22

## Android Carrier link probe crash

- The Android emulator reproduced a native abort when the online call probe
  tried to send to a throwaway contact without a usable Carrier link. Native
  Carrier returned a send error, then JNI released the destination string a
  second time. This stopped the call before its RSP fallback could run.
- The JNI receipt path now releases both borrowed inputs once and transfers
  the receipt callback context only when the native send succeeds.
- Built the arm64 JNI library with NDK 28.2.13676358 and confirmed 16 KB
  alignment. The Android app's local AAR keeps the Java classes and native
  Carrier core from `6.0.5-beagle5` and replaces the JNI library.
